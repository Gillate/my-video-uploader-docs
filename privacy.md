Privacy Policy — My Video Uploader

Last updated: 02.09.2026

This tool processes the following data:

- TikTok OAuth access and refresh tokens — stored locally on the
  user's own computer to authorize video uploads. Never shared with
  third parties.
- Video files and titles — read from a local folder and uploaded
  directly to TikTok via the official Content Posting API. Not stored
  on any external server.
- Scheduling metadata (timestamps) — stored locally.

Data sharing: No data is transmitted to any party other than TikTok's
official API (open.tiktokapis.com).

Data retention: Tokens and settings are stored locally and can be
deleted at any time by removing the app's config folder.
